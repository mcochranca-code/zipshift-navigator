# Figma Make Reference Notes

The supplied Figma Make project, **Emergency Resource Navigator**, is accessible in the user’s browser but remains in a loading state. The supplied screenshot set and EMR source archive provide the actionable visual specification used for this implementation: a fixed deep-navy sidebar, teal active navigation, pale neutral content canvas, white rounded data panels, compact uppercase metric labels, bold dark headings, and filterable tables for operational workflows.

The Admin and Researcher **Cases** and **Reports** views will follow that structure with real role-gated data, case status filters, detailed tables, and export actions.
